# Go2 实机分级测试协议（待人工执行）

本协议只定义 R0-R5 的放行步骤，不代表任何一级已经完成。每一级必须由现场负责人填写日期、操作者、设备编号、软件包哈希并签字。

## 通用前置检查

- 部署包哈希、73 维观测顺序、12 维动作顺序和关节映射核验通过。
- 急停、通信超时、姿态/高度/关节/温度限制与 SAFE_STOP 独立测试通过。
- `frame_id` 在牵引使能、跌倒恢复、估计器重启时更新，历史窗口被清空。
- 首次出现低置信、NaN、时间戳倒退或姿态跳变时，禁止继续放行。

## R0：只读日志

Go2 开机，禁止发送 LowCmd。记录 IMU、关节位置/速度、电机力矩估计、控制时间戳。离线检查范围、偏置、漂移、抖动、丢帧和估计器置信度。

停止条件：时间同步异常、字段缺失、单位/顺序不一致、估计输出非有限值。

## R1：悬空/支架

只允许小幅关节目标，验证关节映射、正负方向、缩放、变化率和急停。

停止条件：任一关节方向或缩放错误、异常振荡、通信超时。

## R2：平地无牵引

限速低速站立、起步、直行、侧移、转向、减速、停止。

停止条件：姿态、力矩、温度、滑移、通信或估计置信度越界。

## R3：轻载牵引

从 5 N 附近开始，逐级验证前后左右方向；每级之间站立复位并人工确认。

停止条件：世界方向错误、跟随响应异常、持续低置信或安全监督器触发。

## R4：中载与方向变化

逐级增加至工程中载范围，加入斜向、垂向组合和显式方向切换。方向切换必须记录事件时间与 jerk。

停止条件：任何未解释失稳、方向漂移、动作峰值或支撑裕度不足。

## R5：目标工况

只在 R0-R4 全部签字通过后执行正式评测。保留原始日志、配置、哈希、视频与停止事件。
